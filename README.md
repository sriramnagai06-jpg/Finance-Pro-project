# FinancePro
**B.Com (CA) Final Year Project**

FinancePro is a comprehensive Personal Finance Management web application designed to help users track their income, expenses, budgets, and generate professional invoices. It features a robust admin dashboard for platform management and includes advanced features such as interactive charts, notifications, and PDF/Print reporting.

## Key Modules
1. **Authentication:** Secure login, registration, and role-based access control.
2. **Dashboard:** KPI summary cards, interactive income vs expense charts, and recent transactions.
3. **Income & Expenses:** Add, view, filter, and track cash flows.
4. **Budget Planner:** Set monthly budgets per category with progress bars and alerts.
5. **Reports:** Monthly and yearly financial breakdowns by category.
6. **Invoices:** Create, print, and track professional invoices with GST calculation.
7. **Settings & Profile:** Customizable themes (Dark/Light mode), currency formats, and company details.
8. **Admin Panel:** Platform overview, user management (block/unblock/delete).
9. **Security:** CSRF protection, SQL injection prevention (Prepared Statements), Password hashing, and XSS sanitization.
10. **Notifications:** Real-time alerts for large expenses, exceeded budgets, and successful logins.

## Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Bootstrap 5.3, FontAwesome, Chart.js.
- **Backend:** PHP 8+ (Core PHP, MVC-inspired structure).
- **Database:** MySQL 8+ (Relational Database with Foreign Keys and Triggers).
- **Architecture:** Client-Server model.
